# Themes

The app supports six themes: Auto, Dark, Light, Dusk, Midnight, and Green. Theme selection is persisted via `SettingsSource` and managed by `Themer`. Each theme maps to a `ColorScheme?` (nil for Auto, `.dark` for Dusk/Midnight/Green) which is applied via `.preferredColorScheme` and `.colorScheme`. Per-theme colors are defined in `ThemeColors` (an `@Observable` class injected via `.environment(themeColors)`). Dusk, Midnight, and Green each have dedicated color sets (`duskAccent`, `duskBackground`, `duskText`, etc.) editable in Xcode's color picker. When the user picks a theme in `SettingsView`, `SettingsViewModel.setTheme` fires a callback to `MainView` which updates both `MainViewModel.colorScheme` and calls `themeColors.apply(theme)`, propagating the change to all views simultaneously.
